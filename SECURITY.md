# Security policy

This repository is private. Report vulnerabilities privately to the repository owners through GitHub Security Advisories or a private channel already agreed with the maintainers. Do not open a public issue for a vulnerability. Include affected revision, impact and reproducible steps. Do not include real user data or credentials.

No service or supported version has been released yet. Do not submit secrets in reports; revoke and rotate exposed credentials immediately. Security features such as secret scanning, push protection, Dependabot alerts and CodeQL depend on repository/organization settings and plan and are not enabled merely by these files.
